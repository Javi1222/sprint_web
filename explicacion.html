Documentación Técnica: Proyecto Full-Stack

Guía de estudio paso a paso para la integración de Frontend, Backend y MySQL.

1. Introducción y Arquitectura

Este documento detalla la construcción de una aplicación web completa estructurada en tres capas independientes. Este diseño asegura que cada componente tenga una responsabilidad única, facilitando la escalabilidad y el mantenimiento del software.

  • Capa de Presentación (Frontend): Desarrollada en HTML, CSS y JavaScript nativo. Se encarga de capturar las interacciones del usuario y comunicarse de forma asíncrona mediante la API fetch().
  • Capa Lógica (Backend): Implementada con Node.js y el framework Express. Actúa como intermediario, procesa las peticiones HTTP, aplica reglas de validación y gestiona la seguridad (CORS, inyecciones SQL).
  • Capa de Datos (Base de Datos): Soportada por MySQL 8.0. Garantiza la persistencia de la información estructural y de los registros de usuarios.

2. Fase 1: Preparación de la Base de Datos

El primer paso metodológico es establecer el modelo de datos físico. Desde la interfaz de línea de comandos de MySQL o mediante MySQL Workbench, creamos el entorno de almacenamiento.

Nota operativa: Nos aseguramos de configurar previamente los permisos del usuario administrador (root o admin) utilizando la instrucción ALTER USER y GRANT ALL PRIVILEGES para garantizar la correcta conexión desde el Backend.
sql 
-- 1. Creación de la base de datos
CREATE DATABASE sprint_web;
USE sprint_web;

-- 2. Creación de la tabla principal para el registro de usuarios
CREATE TABLE usuarios (
    id INT AUTO_INCREMENT PRIMARY KEY,
    nombre VARCHAR(50) NOT NULL,
    apellidos VARCHAR(100) NOT NULL
);

3. Fase 2: Construcción del Backend (Node.js)

El servidor es el núcleo de la aplicación. Recibirá los datos en formato JSON desde el navegador y los inyectará de forma segura en la base de datos.

3.1. Inicialización y Dependencias

Abrimos la terminal integrada del editor (VS Code / Cursor) en el directorio del proyecto y ejecutamos la inicialización del ecosistema Node, seguido de la instalación de los paquetes requeridos.

bash 
# Inicializa el archivo package.json
npm init -y

# Instalación de los módulos esenciales
npm install express mysql2 cors dotenv

3.2. Gestión de Credenciales Seguras (.env)

Para evitar exponer credenciales críticas en repositorios públicos (GitHub), implementamos variables de entorno. Creamos un archivo .env en la raíz del proyecto. Este archivo debe ser excluido en el .gitignore.

.env 
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=tu_contraseña_real_aqui
DB_NAME=sprint_web
PORT=3000

3.3. Lógica del Servidor (server.js)

Implementamos el servidor con Express. Este archivo incluye la conexión a MySQL usando las variables de entorno y define dos endpoints: uno para guardar usuarios (con consultas parametrizadas ? para evitar inyecciones SQL) y otro para crear tablas dinámicamente (con validación Regex).

server.js 
require('dotenv').config(); // Carga las variables del archivo .env
const express = require('express');
const mysql = require('mysql2');
const cors = require('cors');

const app = express();

// Middlewares fundamentales
app.use(cors()); 
app.use(express.json()); 

// 1. Configuración de la conexión a MySQL usando entorno seguro
const db = mysql.createConnection({
    host: process.env.DB_HOST,
    user: process.env.DB_USER,
    password: process.env.DB_PASSWORD,
    database: process.env.DB_NAME
});

db.connect((err) => {
    if (err) {
        console.error('Error crítico: Conexión denegada a MySQL:', err);
        return;
    }
    console.log('¡Conexión exitosa a la base de datos MySQL!');
});

// 2. ENDPOINT: Registro de Usuarios
app.post('/api/usuarios', (req, res) => {
    const { nombre, apellidos } = req.body;
    
    // Consulta parametrizada (los '?' protegen contra SQL Injection)
    const sql = 'INSERT INTO usuarios (nombre, apellidos) VALUES (?, ?)';
    
    db.query(sql, [nombre, apellidos], (err, result) => {
        if (err) {
            console.error('Error insertando datos:', err);
            return res.status(500).json({ error: 'Error interno del servidor' });
        }
        console.log(`Usuario registrado: ${nombre} ${apellidos}`);
        res.status(200).json({ mensaje: 'Datos guardados correctamente' });
    });
});

// 3. Inicialización del puerto de escucha
const PORT = process.env.PORT || 3000;
app.listen(PORT, () => {
    console.log(`Backend operativo en http://localhost:${PORT}`);
});

4. Fase 3: Interfaz de Usuario (Frontend)

El cliente web está diseñado para ser ligero. Utiliza un diseño basado en Flexbox y maneja la comunicación con el Backend de forma asíncrona, proporcionando retroalimentación visual al usuario sin recargar la página.

index.html

<body>

    <div class="card">
        <h2>Registro de Usuario</h2>
        
        <div class="form-group">
            <input type="text" id="nombre" placeholder="Nombre completo" aria-label="Nombre">
        </div>
        <div class="form-group">
            <input type="text" id="apellidos" placeholder="Apellidos" aria-label="Apellidos">
        </div>
        
        <button onclick="registrarUsuario()">Guardar en MySQL</button>
    </div>

    <script>
        async function registrarUsuario() {
            const nombre = document.getElementById('nombre').value.trim();
            const apellidos = document.getElementById('apellidos').value.trim();

            if (!nombre || !apellidos) {
                alert('Atención: Todos los campos son obligatorios.');
                return;
            }

            try {
                // Petición asíncrona al Backend
                const response = await fetch('http://localhost:3000/api/usuarios', {
                    method: 'POST',
                    headers: { 'Content-Type': 'application/json' },
                    body: JSON.stringify({ nombre, apellidos })
                });

                if (response.ok) {
                    alert('Operación exitosa: Usuario almacenado en la Base de Datos.');
                    document.getElementById('nombre').value = '';
                    document.getElementById('apellidos').value = '';
                } else {
                    alert('Error en la transacción del servidor.');
                }
            } catch (error) {
                console.error('Fallo en la comunicación red:', error);
                alert('Error de conexión con el Backend.');
            }
        }
    </script>
</body>
</html>
